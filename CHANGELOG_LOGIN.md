# Login Design Restoration

Restored the pre-cinematic academic login design with the split navy/cream layout from the earlier system UI.

- Responsive two-column layout with tablet/mobile fallback
- No fixed-position cinematic login elements
- Role selection and role-specific login retained
- Existing backend, dashboard, scheduling, feedback, and database functionality preserved
- Dashboard light/dark theme logic remains available after login
- Login page no longer depends on the cinematic black theme or landing video
